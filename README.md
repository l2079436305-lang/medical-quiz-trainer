# 医学题库通关 · 个人题库训练器

一个**纯本地运行**的医学题库随机刷题 Web App。无需安装、无需服务器、无需登录、完全离线，所有数据（题库、做题记录、错题、收藏、统计）只保存在你自己的浏览器里，**不上传任何数据、不调用外部接口、无统计追踪**。

> 本仓库只包含程序代码，**不含任何题库数据**。克隆或下载后，导入你自己的题库即可使用（支持 docx / txt / md / json / csv，见下文）。

## 快速开始

1. 双击打开 `index.html`（推荐 Chrome / Edge 浏览器）
2. 进入「导入 / 导出」页：
   - 直接把题库 **docx / txt / md / json / csv 文件拖入或选择**，或把文本**粘贴**到输入框
   - 点击「解析预览」→ 检查识别数量与异常 → 「确认导入」
3. 回到首页 → 「开始随机练习」→ 选范围和题数 → 随机组题刷题 → 提交自动判分

> 支持的题库写法非常宽松：带题号的纯文本、Word 复制内容、Markdown、文末统一答案区等多种格式都能解析，导入后会先给出识别预览，异常题目可手动修正，不会静默丢弃。

## 功能清单

- **导入**：粘贴文本 / docx / txt / md / json / csv；解析预览（题型分布、答案识别数、异常数）
- **解析兼容**：`(A1型题)` 标注、【题号 1】【休克】A 内嵌答案、`答案：B` / `正确答案：C`、一行挤压的 `A.xxB.yy` 选项、文末统一答案区、Markdown 章节标题等
- **A3/A4 病例组题**：自动把连续的 A3/A4 小问归为一组，支持多种共用题干形式（无编号病例段落 / 编号但无选项的 A3 块 / 上一题尾部段落）；题库中病例描述缺失时会整组标记"病例共用题干缺失"，可在导入页补录（对全组生效）；答题页与结果页显示病例共用题干框和"病例题 第 x/y 问"徽标
- **异常处理**：缺答案 / 缺选项 / 题号重复 / 题型未知 / 病例题干缺失 的题目**绝不丢弃**，逐条列出并提供手动修正
- **题型**：A1 / A2 / A3 / A4 / B1 / 多选(X) / 判断，结构可扩展
- **随机练习**：全部 / 章节 / 题型 / 错题 / 收藏 / 未做 / 最近错误 / 高频错误；题量 5~100 或自定义；随机题序、可选随机选项顺序；同一套不重复；「避免最近 N 次出现过的题目」（默认 N=1）
- **自动判分**：多选题排序比对（AC ≠ ACD）；交卷前不显示答案；交卷后逐题显示 我的答案 / 正确答案 / 解析
- **错题系统**：错题自动入错题本；连续答对 2 次降低优先级、3 次标记基本掌握；再做错重新进入高优先级
- **统计 Dashboard**：今日做题/正确率、总题数/完成率/总正确率、错题/收藏/未做/已掌握；章节统计（可点击直接练习）、题型统计、历史练习记录
- **继续上次练习**：答题中途退出，进度自动保留
- **导出**：题库（JSON / TXT / Markdown）与学习记录（JSON）
- **移动端**：响应式布局，手机浏览器可用

## 数据与隐私

- 存储位置：浏览器 LocalStorage（`medquiz.v1.*` 键）
- 不发起任何网络请求（可断网使用；页面无任何外部脚本/字体/图片引用）
- docx 解析使用浏览器原生 `DecompressionStream`，零第三方依赖
- 清除数据：导入页底部「清空全部本地数据」

## 目录结构

```
index.html            入口页面
css/style.css         样式（简洁医学工具风，移动端适配）
js/parser.js          题库解析器（纯函数，可独立测试）
js/docx.js            浏览器内 docx 解压与文本提取
js/storage.js         本地存储层（LocalStorage）
js/question-bank.js   题库数据层（索引/筛选/记录/掌握度）
js/quiz.js            考试逻辑（抽题/会话/判分/记录回写）
js/statistics.js      统计逻辑（Dashboard/章节/错题本/历史）
js/exporter.js        导出（JSON/TXT/MD/学习记录）
js/ui/dom.js          DOM 工具
js/views/*.js         界面（home/setup/quiz/result/stats/import）
test/                 Node 单元测试 + 集成测试 + 浏览器 E2E
```
